# WardenMenu

Меню сервера, которое настраивается целиком в конфиге — без правки кода под каждую кнопку.

## Что внутри

**Меню из конфига.** Любое число меню, у каждого свои заголовок, число рядов и предметы по слотам.
Кнопка умеет: открыть подменю, выполнить команду, дать кликабельную ссылку,
показать личную статистику, показать топ, закрыть окно.

**Статистика.** Убийства игроков и мобов, смерти, К/Д, наигранное время.

**Топы.** По убийствам, онлайну, смертям и балансу (через Vault, если он есть).
Считаются по таймеру и кешируются, а не на каждый клик.

**Защита.** Из меню ничего не вынести: клики и перетаскивания в нём отменяются.

## Команды

`/menu [id]`, алиасы `/m`, `/hub`.

## Настройка

`menus.<id>.title / rows / items.<слот>.{material,name,lore,action}`,
`tops.refresh-minutes`, `tops.size`.

## Зависимости

Vault — опционально, только для топа по балансу.

## Сборка

```bash
JAVA_HOME=/usr/lib/jvm/java-21-openjdk mvn package
```

Готовый `.jar` — в `target/`.
